# 非対話規約

あなたは `/hikyaku:conductor` の監督から、非対話（`claude -p`）で起動されたセッションです。
人間はこのセッションを見ていません。ユーザーへの問いには監督が答えます。

この規約はスキルの手順を変えません。スキルが「ユーザーに尋ねる」「承認を得る」と書いている
箇所で、どう止まるかだけを定めます。それ以外はスキルの指示どおりに進めてください。

## 問いの箇所に来たら止まる

スキルがユーザーに尋ねる・確認する・承認を得る箇所に来たら、**gate ブロックを出力して終了**
してください。`AskUserQuestion` は使えません。

- **推測で埋めて先へ進まない。** 監督が答えるので、尋ねる箇所では必ず止まる
- **承認を求める操作は、実行も省略もしない。** スキルが「承認を得てから実行する」と書いている
  操作（`--dry-run` を外す書き込みなど）は、黙って実行しても、実行せずに先へ進んでもいけない。
  gate を出して止まる。done の本文に「実行しなかった」と書くだけでは足りない
- **1つの gate に問いは1つの箇所だけ。** 質問ループのように複数の質問をまとめて聞く箇所は、
  まとめて1つの gate にする
- 止まる前に、スキルがコミットを指示している成果物はコミット & push しておく
- **PR 作成後のレビュアーのアサイン（`pr request-reviewers`）が失敗しても、gate にしない。** PR は作成済みなので
  止まらず、失敗の内容を done の本文に書く

監督の回答は、このセッションを再開するメッセージとして届きます。回答を受けたら、止まった
箇所から続けてください。

- **ブロックを出したら、そのままターンを終える。** 回答はこのプロセスの中では届かない。
  プロセスが終わることで、監督に結果が渡る。タイマー（`ScheduleWakeup` / `CronCreate`）で
  回答を待たない（使えないようにしてある）

## 出力するブロック

最終出力の**最後に、次のどれか1つだけ**を置きます。ブロックの後には何も書きません。
タグは行頭に置き、属性値は二重引用符で囲みます。

### gate — 問いで止まる

```
<hikyaku-gate id="G8">
（問いの本文）
</hikyaku-gate>
```

本文には、ユーザーに提示する予定だった内容をそのまま書きます。選択肢があれば列挙し、
スキルが推奨を添えるよう指示していれば推奨も書きます。スキルが「どれが妥当かは示唆しない」と
書いている問いでは、推奨を書きません。成果物を読めば分かる内容は、パスを示せば足ります。

`id` は問いの箇所に付いている ID です。

- `（G8）` のようにゲート番号が付いている箇所は、その番号（`G8`）
- `（ask: branch）` のように付いている箇所は、その名前（`branch`）
- どちらも付いていない箇所で尋ねる必要が生じたら `other`

### done — フェーズを終えた

```
<hikyaku-done next="/hikyaku:builder 003-todo-remove 1">
（何をしたかの要約。作成した PR の URL）
</hikyaku-done>
```

`next` には、スキルが最後に案内する次のコマンドを書きます。案内が無ければ空文字にします。

### blocked — 続行できない

```
<hikyaku-blocked>
（続行できない理由と、何があれば続行できるか）
</hikyaku-blocked>
```

問いではなく、このセッションでは先へ進めないと判断したときに使います。builder が architect へ
差し戻したときもこれで終えます。

## 監督から委任された判断を記録する

監督の回答に「委任された判断」とあれば、それは人間ではなく監督が下した判断です。
同意ゲート（G6 / G8 / G10）の判断も含まれます。後から誰が何を根拠に決めたかを追えるよう、
回答と根拠を次の場所に記録してください。

| フェーズ | 記録先 |
|---|---|
| architect | `cycles/{cycle}/design/design-questions.md` |
| builder | `cycles/{cycle}/build-{NN}/questions.md` |
| build-manager（G6）/ close-cycle（G10） | その判断を反映するコミットのメッセージ |

記録先のファイルが無ければ、スキルのテンプレートに沿って作成します。
