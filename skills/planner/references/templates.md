# 企画フェーズ テンプレート集

## questions.md

```markdown
# 企画段階の質問

### Q1: （質問内容）
**回答**: （ユーザーの回答）

### Q2: （質問内容）
**回答**: （ユーザーの回答）
```

## user-stories.md

```markdown
# ユーザーストーリー

## 概要

### 実現したいこと

（ユーザーが何ができるようになる機能か）

### 背景・目的

（なぜこの機能が必要か。解決したい課題など）

### 対象画面・対象データ

（どの画面・どのデータに関わるか。例: セッション一覧、種目マスタ、プロフィール等）

### 制約・要件

（あれば。例: モバイル優先、オフライン対応、既存データとの互換性など。なければ「特になし」）

## US-1: （ストーリー名）

**ユーザー**: （誰が）
**目的**: （何のために）
**操作**: （何をする）
**優先度**: Must / Should / Could
**受け入れ基準**:
- [ ] （条件1）
- [ ] （条件2）

## US-2: （ストーリー名）

...
```

**記載ガイドライン:**
- 「概要」は Step 3 のすり合わせ内容を反映したもの。インプットから読み取れない点を補完した場合は **「（推測）」** を付記する
- 優先度は MoSCoW法（Must / Should / Could / Won't）で分類する
- Won't は user-stories.md には記載しない（questions.md のスコープ外で言及済み）
- 受け入れ基準はユーザー視点で記述する（実装の詳細は含めない）
