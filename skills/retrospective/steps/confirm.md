# confirm: 振り返りを実施するかの確認

`retrospective` が `prompt` のときだけ、step はこのステップを返す（`auto` なら確認せずに進む）。

- [ ] ユーザーに振り返りを実施するか確認する（ask: retrospective）

```
振り返りを実施しますか？（y/n）
振り返りではセッション中のスキル外指示を分析し、スキルやインストラクションの改善提案を作成します。
```

- [ ] 実施するなら `done` を報告し、返った1手に従って続ける
- [ ] 不要なら `skipped` を報告する（`--reason` にユーザーの答え）。残りのステップは対象外になり、
  `done` が返るので、呼び出し元に戻る
