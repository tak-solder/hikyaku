# G3: 設計案の選択

`design_choice_gate` が有効なとき（economy / standard / thorough）に、分岐がある判断があれば返るゲート。
トレードオフの選択は本来人間にしか下せない判断なので、外せるのは express だけ。

- [ ] `options` でまとめた trade-off表と推奨案をユーザーに提示し、選択を得る（G3）
- [ ] 「お任せ」と回答された場合も、推奨案を改めて提示して明示的な確認を得る（空回答として進めない）
- [ ] 選択を得たら `approved` を報告する（`--input` にユーザーの答え。選んだ案が分かるように書く）
- [ ] 案の作り直しを求められたら `rejected` を報告し（`--input` にユーザーの答え）、案を見直してから
  `step next` に従って提示し直す
- [ ] progress.jsonl をコミット & push する
