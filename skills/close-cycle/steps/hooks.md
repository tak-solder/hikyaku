# hooks: フックを採るかの記録

サイクルの記録にフックの候補があったので、G10 での決定を記録する。フックそのものはここでは書かない
（PR を作ったあとの followups で、別のブランチの PR にする）。

followups は、この記録からフックの PR を作るかを決める。承認の答えは自由な文章で、セッションが
切れると読み取れなくなるため、決定をここで形にして残す。

- [ ] G10 の承認で、フックの候補を1つでも採ると決まっていれば `done` を報告する
- [ ] 1つも採らないと決まっていれば `skipped` を報告する（`--reason` に、採らない理由）

承認の答えからどちらか読み取れなければ、推測せずユーザーに確かめる（ask: G10）。
