# retrospective: 振り返り

`/hikyaku:retrospective {cycle} build-{NN}` を呼び出す。実施するかの確認（`prompt`）や、予測ピークの実測の収集・
記録の形は retrospective の手順が決める。

- [ ] 戻ったら `done` を報告する。振り返りを実施しないとユーザーが答えた場合も `done` でよい

PR を作る前に行い、retrospective.md と progress.jsonl をローカルでコミットする。push は次の pr で
PR を作る直前にまとめて行う（このステップの報告後も push しない）。
