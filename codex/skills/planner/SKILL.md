# Hikyaku planner (Codex)

[Codex 実行規約](../../compatibility.md)を読んでから、[planner の元の手順](../../../skills/planner/SKILL.md)を最後まで読み、この依頼に適用する。

元の手順の成果物、設定、承認、レビュー、終了条件を守る。Codex と Claude Code の呼び出し方が異なる箇所には Codex 実行規約を適用する。
