## 永続化すること

- `workflow` [中]: conductor の子で `node scripts/hikyaku.mts conductor lint`（リポジトリの CLI）を実行するには、`[conductor] allowed_tools` に足す必要がある。既定の許可はプラグインの CLI の実行だけで、AGENTS.md が求める `conductor lint` を子が実行できない（build-14 と build-19 で実行できず、差分の確認で代えた）
- `upstream`: builder の review の指示は `review run` を `run_in_background` で実行させるが、conductor の子（非対話）では `Monitor`・`sleep`・複合コマンドが許可されず、完了を待つ手段が無い。Stop フックに引き止められたうえで `timeout 590 tail -f <出力>` で待った。非対話ではフォアグラウンドで実行させる（数分で終わる）
- `upstream`: conductor の子では `sed -i` や `git -C` が許可されず、多数の行の置き換えを Edit で1か所ずつ行った。用語の置き換えのような多ファイルの小さな編集のビルドでは、予測ピークの実装の成分に Edit の呼び出し回数分を見込む
